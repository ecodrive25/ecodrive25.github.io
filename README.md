# ECODRIVE25 – site vitrine

## Mettre en ligne GRATUITEMENT avec GitHub Pages
1. Créez un compte sur github.com.
2. Bouton « + » → « New repository » → nom : `ecodrive25` → Public → Create.
3. « uploading an existing file » → glissez TOUS les fichiers (index.html, robots.txt, sitemap.xml, dossier images…) → Commit.
4. Settings → Pages → Source : « Deploy from a branch » → branche `main`, dossier `/ (root)` → Save.
5. Après 1 à 2 minutes, le site est en ligne : https://VOTRE-PSEUDO.github.io/ecodrive25/
6. Dans index.html, robots.txt et sitemap.xml, remplacez `VOTRE-PSEUDO` par votre nom GitHub.

## Railway (optionnel)
Railway → New Project → Deploy from GitHub repo → choisir `ecodrive25`.
Railway lit package.json et lance `npm start` tout seul. Puis Settings → Networking → Generate Domain.

## Référencement Google (gratuit)
1. search.google.com/search-console → ajouter votre adresse → envoyer `sitemap.xml`.
2. business.google.com → créer la fiche « ECODRIVE25 » (le plus important pour « ménage Pont-de-Chéruy »).
3. Mettre le lien du site sur la fiche Google, Facebook, PagesJaunes (gratuit).
4. Demander des avis Google à chaque client satisfait.
